# 选品确认清单

本清单用于 `product-research` 的过滤、打分和报告归因。具体平台策略还需读取 `references/platforms/` 下对应文件。

| 确认项 | 为什么要确认 | 主要落点 |
|---|---|---|
| 目标平台/站点 | 平台流量、规则、合规和物流不同 | 任务路由、市场范围 |
| 流量类型 | 搜索流量和推荐流量的选品标准不同 | 平台适配评分 |
| 市场需求 | 避免只看单个爆款或自嗨判断 | 需求评分 |
| 趋势/季节性 | 防止错过窗口或造成库存滞销 | 趋势风险 |
| 竞争强度 | 判断是否红海、广告成本是否可承受 | 竞争评分 |
| 评论/信任门槛 | 新品能否获得转化 | 评论护城河 |
| 差异化空间 | 没差异化容易陷入价格战 | 机会说明 |
| 用户痛点 | 决定产品改良和内容卖点 | VOC 分析 |
| 价格带 | 影响毛利和转化 | 利润测算 |
| 采购价/MOQ | 影响首批资金和测款风险 | 资金过滤 |
| 物流尺寸重量 | 影响头程、尾程、入仓和退货 | 物流风险 |
| 合规/资质 | 决定是否能上架和是否需额外费用 | 一票否决/待核实 |
| 侵权/敏感属性 | 影响下架、罚款、账号风险 | 一票否决 |
| 供应链能力 | 决定能否稳定供货和差异化 | 能力匹配 |
| 内容素材能力 | 推荐电商和 DTC 转化关键 | 能力匹配 |
| 广告依赖度 | 广告能力弱的卖家不适合高 CPC 品 | 能力匹配 |
| 售后复杂度 | 影响退货、差评和客服成本 | 风险评分 |
| 复购/LTV | 影响长期价值 | 软性加分 |
