# TikTok / 推荐电商选品策略

知识类型：经验型策略。价格带、客诉率等数字不得作为事实标准，需按实际账号和数据验证。

## 要处理的数据

| 数据 | 用途 |
|---|---|
| 热门视频 / 互动数据 | 判断内容传播潜力 |
| 评论痛点 / 用户提问 | 判断真实需求和转化阻碍 |
| 产品价格带 | 判断冲动购买可能性和利润空间 |
| 物流时效 / 轨迹可查性 | 判断客诉、退货、收款风险 |
| 视觉冲击 / 演示效果 | 判断素材可拍性 |
| 目标人群 | 判断产品风格、价格和内容表达 |

## 策略重点

- TikTok 属于推荐流量，选品必须和内容素材一起判断。
- 优先看产品是否有新奇特、视觉演示、痛点共鸣、场景带入、情绪价值。
- 如果产品无法在短视频里迅速解释或展示，推荐流量转化难度会增大。
- 物流时效过长会带来退货、客诉、收款账号风险，应作为重要风险项。
- 高客单价产品需要更强信任建设和更长转化链路，不适合所有卖家。

## 过滤信号

- 物流不可控或无法提供可靠轨迹。
- 内容团队无法拍出清晰演示或差异化素材。
- 产品需要复杂解释、强售后或高信任背书。
- 与目标人群年龄、消费力、文化语境不匹配。

## 打分信号

- 三秒内能看懂用途或痛点。
- 视频展示前后对比明显。
- 评论区能持续产生问题、共鸣或购买意向。
- 适合礼品、节日、情绪价值或热点场景。
- 供应链支持快速测款和小批量迭代。
