# Shopify / 独立站 / SEO 选品策略

知识类型：经验型策略。搜索量、KD、CPC 等以实际工具数据为准。

## 要处理的数据

| 数据 | 用途 |
|---|---|
| 关键词搜索量 / KD / 趋势 | 判断长期搜索需求和竞争难度 |
| 竞品站 / 产品页 / 内容结构 | 判断差异化、转化路径、内容门槛 |
| Affiliate 外链 / 推荐链接 | 发现被内容站验证过的热销或小众品 |
| Shopgram / 店铺榜单 / 类目热度 | 观察 Shopify 类目和店铺竞争情况 |
| 复购 / 耗材 / 搭卖可能 | 判断 LTV 和长期商业价值 |

## 策略重点

- 独立站和 SEO 更依赖长期内容、关键词布局、品牌信任和转化链路。
- 优先寻找搜索量存在、竞争不过分激烈、能持续产出内容的 niche。
- 关键词没有统一叫法时，需要判断多个近似词的总需求，而不是只看单个词。
- 复购、耗材、配件、搭卖、套装和人群一致性会显著影响长期价值。
- 单品本身好不够，还要确认是否能获取流量和建立信任。

## 过滤信号

- 关键词需求过弱，或全部核心词竞争极高。
- 产品没有内容话题、品牌故事或差异化页面空间。
- 物流、售后、支付或信任成本超过卖家能力。
- 需要长期 SEO 投入，但卖家没有内容能力。

## 打分信号

- 搜索需求稳定或上升。
- 关键词竞争存在可进入空间。
- 产品有明确内容资产：教程、测评、对比、场景、买家指南。
- 具备复购、耗材、配件、搭卖或系列化潜力。
- 供应链能支撑品牌化包装和持续供货。
