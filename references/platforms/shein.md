# SHEIN 全托管选品策略

知识类型：经验型策略。平台费用、罚款、认证费等数字必须另行核实。

## 要处理的数据

| 数据 | 用途 |
|---|---|
| 机会商品 / 稀缺爆款 / 潜力趋势 | 判断平台当前希望补充什么供给 |
| 同款商家数 | 判断供给稀缺度 |
| 近期销量 / 当季需求 | 判断是否有短期和季节窗口 |
| 供货价 / 1688 采购价 | 判断单件利润空间 |
| 资质提示 | 判断是否需要证书或认证 |
| 重量 / 体积 / 材质 / 易损属性 | 判断物流成本、破损和罚款风险 |

## 策略重点

- 先理解平台规则，再选品。平台发品额度、上架审核、新品销量考核、机会商品权益都会影响结果。
- 新商优先从平台机会入口找品，尤其关注平台已有需求但供给不足的款式。
- 优先考虑"日常可卖，节日或多人场景更好卖"的普货，降低纯节日品滞销风险。
- "多人/聚会/活动场景"可能带来一次多件购买或节日放量，但仍需验证日常需求。
- 核心判断是：近期或当季需求高，同时 SHEIN 同款商家少。

## 避选信号

- 需要证书的新手难处理品类，如儿童用品、食品接触、部分首饰等，具体以平台资质提示和 references 为准。
- 敏感品：电池、粉末、颗粒、刀具、液体、气体等。
- 侵权、宗教敏感、平台禁售或图片高风险。
- 重量体积大，或单边尺寸明显不适合低价跨境物流。
- 陶瓷、树脂等易损品，或包装要求高但卖家无法控制。

## 打分信号

- 来自机会商品或稀缺爆款入口。
- 同款少，平台需求明确。
- 普货属性强，节日也能放大。
- 小件、轻货、不易损、不敏感。
- 采购价与供货价之间有可验证利润空间。
