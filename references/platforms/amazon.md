# Amazon 平台选品策略

知识类型：经验型策略 + 待接入数据字段说明。事实费用以官方或已核实 references 为准。

## 要处理的数据

| 数据 | 用途 |
|---|---|
| 类目 Top100 / BSR | 判断市场规模、价格带、品牌集中度、头部垄断程度 |
| 关键词搜索量 / CPC / 竞争度 | 判断搜索需求、广告门槛、关键词是否可打 |
| 评论数 / 评分 / 上架时间 | 判断评论护城河、新品机会、质量风险 |
| Listing 标题 / 图片 / 五点 / A+ | 判断卖点、差异化、内容门槛 |
| 差评 / 问答 / 退货线索 | 挖掘痛点、退货原因、产品改良方向 |
| 采购价 / 头程 / FBA / 佣金 / 广告预估 | 计算真实毛利和资金占用 |

## 策略重点

- Amazon 属于搜索电商，优先确认用户是否会主动搜索该产品或关键词。
- 推荐优先找"需求真实、评论门槛不过高、广告成本可承受、差异化明确"的品。
- 对新手或广告能力弱的卖家，高 CPC、高评论护城河、强品牌垄断类目应降权。
- 差异化应落在可感知位置：外观、规格、套装、材质、场景、功能改良、内容呈现。
- 只看销量不够，必须同时看利润、广告依赖、合规、物流、退货和供应链。

## 过滤信号

- 违反卖家禁做类目或禁做属性。
- 需要卖家没有能力处理的认证、危险品、侵权或高售后风险。
- 预估单品投入超过 `profile.constraints.capital_per_sku_max`。
- 毛利测算低于 `profile.preferences.margin_floor_pct`。

## 打分信号

- 市场需求强且趋势稳定。
- 关键词有搜索量，竞争不过度集中。
- 竞品评论数低于卖家的评论门槛。
- 差评暴露出可解决痛点。
- 供应链能支持差异化或稳定交付。
