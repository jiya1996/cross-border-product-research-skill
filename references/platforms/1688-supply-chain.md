# 1688 / 供应链反推选品策略

知识类型：经验型策略。采购价、MOQ、交期等必须以供应商实时报价为准。

## 要处理的数据

| 数据 | 用途 |
|---|---|
| 采购价 / 阶梯价 | 判断毛利空间 |
| MOQ / 打样费 | 判断首批资金压力 |
| 交期 / 补货周期 | 判断断货和现金流风险 |
| 产业带 / 工厂专业度 | 判断供应稳定性和成本优势 |
| 是否支持定制 / 私模 / 包装 | 判断差异化能力 |
| 是否懂 Amazon / 跨境 | 判断合作效率和合规意识 |

## 策略重点

- 有市场需求不等于卖家能做，供应链决定落地能力。
- 优先找专业单一类目的工厂或供应商，而不是杂货铺。
- 供应商是否位于产业带、是否配合小批量测试、是否能稳定补货，是选品能否持续的关键。
- 如果目标平台需要差异化，供应商是否支持定制、套装、包装和质量控制要提前确认。
- 采购价只是起点，还要叠加头程、平台费、广告、退货和合规成本。

## 过滤信号

- MOQ 超过资金上限。
- 交期太长且无法安全补货。
- 供应商不稳定、品控不可控、无法提供基础资料。
- 无法支持目标平台必要的合规、标签、包装或售后要求。

## 打分信号

- 采购价有足够毛利空间。
- MOQ 适合小批量测款。
- 供应商专业、配合度高、交期稳定。
- 能支持定制或差异化。
- 有跨境平台服务经验。
