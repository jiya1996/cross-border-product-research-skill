# 平台数据源映射

本文件描述各平台选品分析需要的数据字段、优先来源和输出用途。实际接入时，字段名以 MCP 或平台 API 返回为准。

| 平台/来源 | 必需数据 | 推荐数据 | 主要用途 |
|---|---|---|---|
| Amazon | 类目 Top 产品、价格、评论数、评分、关键词、ASIN、数据窗口 | CPC、BSR/销量趋势、差评、Listing 内容、类目/商品/品牌/卖家集中度、自然/广告流量结构、FBA/佣金估算 | 市场规模、竞争度、广告依赖、差异化、毛利 |
| SHEIN | 机会商品、同款供给、供货价、资质提示、基础属性 | 稀缺爆款、潜力趋势、近期销量、上架权益 | 平台需求、同款稀缺度、资质/敏感风险、供货利润 |
| TikTok | 热门视频、互动、评论、商品价格、物流方案 | 创作者素材、广告素材、受众画像、转化数据 | 素材可拍性、推荐流量匹配、痛点和情绪价值 |
| DTC / SEO | 关键词搜索量、KD、趋势、竞品站、产品页 | Affiliate 外链、Shopgram 类目、内容结构、反链来源 | SEO 机会、长期流量、品牌内容和 LTV |
| Reddit | subreddit、帖子、评论、upvote、竞品提及 | 发帖时间、用户画像、重复痛点、反对意见 | 需求验证、痛点提取、产品改良和文案语言 |
| 1688 | 采购价、MOQ、交期、供应商信息 | 产业带、定制能力、包装、跨境经验、样品信息 | 供应链可行性、成本、差异化和补货风险 |

## 数据处理纪律

- 原始数据应保存在报告运行目录的 `raw/` 或等价缓存目录，便于复盘。
- 事实数字必须保留来源字段：数据源、采集日期、站点/市场、计算公式。
- 同一 ASIN、类目或关键词 7 天内可复用缓存，除非用户要求刷新。
- 缺少关键字段时，不要补编，报告中写"需人工核实"。

## Amazon 来源能力映射

| provider / 能力 | 来源角色 | 可进入字段 | 不得证明什么 |
|---|---|---|---|
| 卖家精灵产品/市场/关键词/集中度/CPC | `direct_market_data` | ASIN、价格、评分、评论、销量/BSR 趋势、搜索量、购买率、集中度、CPC、流量词 | 估算销量不是 Amazon 官方实销；CPC 不等于转化 |
| SIF 市场/关键词/流量/广告 | `direct_market_data` | 搜索量、竞争密度、需求结构、自然/广告流量、广告依赖 | 单一流量结构不能证明完整市场需求 |
| 领星/亚马逊广告报告 | `seller_first_party_data` | 当前卖家历史销量、利润、库存、退货、广告表现 | 不能外推全市场规模或其他卖家的表现 |
| 知无不言/讲师案例 | `experience_reference` | 假设、风险清单、验证问题 | 不能提供事实数字、硬过滤或精确分数 |
| AMZ123 | `discovery_only` | 原始网站入口 | 导航页本身不是事实来源 |
| 虎步 RPA | `collection_only` | collector 元数据 | 不替代 Amazon/领星等原 provider |
| Google 翻译/LinkFox 创意 | `transformation_only` | transformation 元数据、素材验证 | 不证明需求、销量、利润或真实转化 |
| 紫鸟浏览器 | `capability_context` | 仅在画像确认后说明运营环境 | 账号环境不是选品数据 |

完整能力白名单与禁止项见 `tool-role-registry.json`。同一品牌包含读写两类能力时，必须按实际工具名启用只读 allowlist。
