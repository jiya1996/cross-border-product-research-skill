# 知识库使用规则

本目录用于支持选品 Agent 的判断，但不同知识的可信等级不同。所有 skill 必须先判断知识类型，再决定如何引用。

## 知识类型

| 类型 | 说明 | 是否可作为事实数字 |
|---|---|---|
| 事实型知识 | 运费公式、平台费率、认证费用、税费、合规要求、官方规则、可核验数据字段 | 可以，但必须标注来源 |
| 经验型知识 | 生财帖子、卖家复盘、案例方法论、运营经验、平台打法总结 | 不可以，只能作为策略启发 |
| 用户画像知识 | `sellers/{seller_id}/profile.yaml`、`sop.md`、决策日志 | 可以作为个性化约束和归因来源 |
| 推断型知识 | 根据已售产品、历史行为、访谈内容推断出的偏好或能力 | 未确认前不得参与过滤或打分 |

## 引用纪律

- 运费、合规、认证、税费、平台费用等事实数字，只能来自 `references/` 中明确标注来源的事实型文件或公式。
- 生财内容、用户帖子、案例复盘只能标注为"经验观点"，不得写成通用事实。
- 经验阈值可以用于启发提问或生成假设，但不得作为一票否决规则，除非用户确认写入 SOP。
- 平台策略文件用于选择分析路径，不替代目标卖家的画像和 SOP。
- 当平台策略与卖家画像冲突时，以卖家画像和 SOP 为准。

## 输出要求

报告中引用知识时，应分清：

- `画像依据`：来自卖家 profile / sop / decisions。
- `数据依据`：来自 MCP、平台数据、已核实 references。
- `经验依据`：来自平台策略知识库或生财方法论。
- `待核实项`：references 未覆盖或来源不足的事实数字。
